> kubectl logs deployment/orderservice-deployment // View application logs
> kubectl delete pod <POD-NAME> //delete pod. The Deployment immediately creates another one. That is Kubernetes self-healing.
> kubectl scale deployment orderservice-deployment --replicas=0 // To intentionally turn a service off, scale its Deployment to zero
> kubectl scale deployment orderservice-deployment --replicas=1 // To intentionally turn a service on

> kubectl apply -f .\k8s\nginx-service.yaml
> kubectl apply -f .\k8s\nginx-deployment.yaml
Meaning:
> kubectl apply → create or update what the file describes.
-f → use a file.
.\k8s\nginx-pod.yaml → the file(path + name) to use.
