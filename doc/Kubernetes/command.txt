> kubectl apply -f .\k8s\nginx-service.yaml
> kubectl apply -f .\k8s\nginx-deployment.yaml
Meaning:
kubectl apply → create or update what the file describes.
-f → use a file.
.\k8s\nginx-pod.yaml → the file(path + name) to use.
