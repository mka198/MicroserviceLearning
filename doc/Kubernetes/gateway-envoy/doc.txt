---------------------- Envoy ---------
Think of Envoy Proxy as a high-performance proxy used in modern microservice architectures.
Envoy is not a gateway, but it can be used as an API Gateway.


In my project, Postman calls one address, and Envoy routes /api/orders to OrderService and /api/inventory to InventoryService.

Envoy can handle:
•	Service discovery
•	Load balancing
•	TLS/mTLS
•	Traffic routing
•	Retries
•	Circuit breakers
•	Observability (metrics, tracing, logs)

What Envoy does:
• Receives requests.
• Finds the correct service.
• Load balances between instances.
