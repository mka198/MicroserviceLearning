1. What is Helm?
Helm is a package manager for Kubernetes.

----- to understand better example: -
you have these files in kubernetes:
deployment.yaml
service.yaml
ingress.yaml
configmap.yaml
secret.yaml

then you have to run following command for above yml file:
> kubectl apply -f deployment.yaml
> kubectl apply -f service.yaml
> kubectl apply -f ingress.yaml

If you use helm, Instead of above command seperately, you can done by helm at once with one command.
Helm deploys everything at once:
> helm install myapp .

above command means: Install the chart in this folder as a release named myapp

-------  A Helm Chart is like a project/package. -----------
myapp-chart/
├── Chart.yaml
├── values.yaml
└── templates/
    ├── deployment.yaml
    ├── service.yaml
    └── ingress.yaml

--------------- helm values.yaml file ------
replicaCount: 3

image:
  repository: nginx
  tag: local

Then kubernetes yaml file will be:

spec:
  replicas: {{ .Values.replicaCount }}

  containers:
  - image: {{ .Values.image.repository }}:{{ .Values.image.tag }}

  ----------- for diff env ------
  helm/
├── Chart.yaml
├── values.yaml
├── values-local.yaml
├── values-staging.yaml
└── values-prod.yaml

----------------- If you use helm: then no need k8s/inventoryservice-deployment.yaml. k8s/inventoryservice-service.yaml. ----
This is for kubernetes:
k8s/inventoryservice-deployment.yaml
k8s/inventoryservice-service.yaml

when you use helm, the above kubernetes files will move to 
helm/inventoryservice/templates/deployment.yaml
helm/inventoryservice/templates/service.yaml
