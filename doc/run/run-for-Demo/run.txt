---------------- Scale down RabbitMQ and Scale down inventory ----------
1. Scale down RabbitMQ 
 > kubectl scale deployment rabbitmq-deployment --replicas=0
 > kubectl get pods -l app=rabbitmq

2. Scale down inventory
 > kubectl scale deployment inventoryservice-deployment --replicas=0
 > kubectl get pods -l app=inventoryservice

3. Create order

4. Scale up RabbitMQ and check order receive by RabbitMQ
> kubectl scale deployment rabbitmq-deployment --replicas=1
> kubectl get pods -l app=rabbitmq -w
> kubectl scale deployment inventoryservice-deployment --replicas=3  #make 3 replica for load balance show

5. Scale up Inventory and check Inventory service consume it.
> kubectl scale deployment inventoryservice-deployment --replicas=1
> kubectl get pods -l app=inventoryservice -w

6. Check DB

7. Load balance  # Show it in postman header, diff pod name
