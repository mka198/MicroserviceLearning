 Command: 
> docker compose config  //validate compose file
> docker compose up -d --build orderservice // build and start order service
> docker compose up -d --build inventoryservice  // build and start inventory service
> docker compose start orderservice // start existing container. It does not build or create container.
> docker compose up -d sqlserver //start only the sqlserver service from compose.yaml. sqlserver-> service name
> docker compose up -d rabbitmq  // start only rabitmq service
> docker compose ps // shows running container
> docker compose logs inventoryservice
> docker compose logs orderservice 
> docker compose up
> docker compose down

| Situation                                                      | Command                                     |
| -------------------------------------------------------------- | ------------------------------------------- |
| Container already exists but is stopped; just run it again     | docker compose start orderservice         |
| First time creating the service                                | docker compose up -d orderservice         |
| You changed C# code/Dockerfile and need a new image            | docker compose up -d --build orderservice |
| You changed Compose configuration and need Compose to apply it | docker compose up -d orderservice         |


 


 -----
 In Docker Compose, containers on the same Compose network can normally communicate using the Compose service name as the hostname.
